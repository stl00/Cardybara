Cardybara · 独立钱包预览 1.2.0

仅本机安装 · 不发布线上 · 原扩展保留

安装包包含完整的 React + Ant Design 钱包和银行采集工具，不依赖 localhost 或 Codex。安装包不含你的卡片或账户快照；可从旧钱包导出备份，再在独立钱包导入。

权限与数据

  • 基础权限：scripting、storage、alarms，以及现有七家银行和既有私人钱包网站的指定域名。
  • 新增可选模型权限：api.deepseek.com、generativelanguage.googleapis.com。默认未授权，只有用户点击连接所选模型时请求。
  • 模型 API 密钥只存本次 Chrome 会话，不写入钱包备份，不发送到 Cardybara 网站。
  • 只有用户预览片段并明确勾选发送给所选模型后，才发送该页财务片段；可能包含余额、积分、优惠、商户及交易金额日期。请自行检查脱敏预览。
  • AI 不执行代码或任意点击，不能付款、转账、兑换、添加优惠或填写银行凭据。结果须核对后选中保存。

实际验收范围

规则采集此前实测香港 Amex 两卡、香港汇丰七卡及部分 Chase 金额。AI 已完成本地协议、证据校验、取消与恢复的模拟测试，尚未配置真实模型密钥，未承诺七家银行所有积分、优惠、交易页面均已跑通。新卡发现、PDF、无限滚动和全自动遍历尚未实现。
